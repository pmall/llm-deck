Demystifying LLMs 2

The LLM

The LLM: a statistical function

  • An LLM is one statistical function that understands a text and predicts what follows.
  • The input text is everything it knows about the task at hand.
  • Billions of parameters hold everything it learned from human text.
  • Chatbots, thinking models and agents are all built on this one function.
  • This chapter shows what “it predicts the next word” means exactly.
Demystifying LLMs 3

The LLM

Parameters: a lossy zip file of human knowledge

  • Training sets billions of parameters from trillions of words of human text.
  • The parameters can be seen as the compression of all existing human text into a zip file.
  • Metaphorically, this zip file contains the infinity of all plausible documents.
  • Compressing human text a hundredfold leaves no choice but some form of understanding.
Demystifying LLMs 4

The LLM

Attention: words take their meaning from each other

  • Each word starts from a base meaning, the same in every text.
  • Attention blends in the meaning of the other words that count.
  • Base meanings and how much each word counts are both learned.
Demystifying LLMs 5

The LLM

Tokens: the vocabulary of the LLM

  • All human text is encoded with one fixed vocabulary of about 256,000 tokens.
  • Tokens are frequent small slices of text rather than words.
  • A rare word is split into several frequent tokens.

The LLM

Zoom on one step: the LLM outputs probabilities

llm(

)=
mat45%
floor18%
sofa12%

+ 255,996 other tokens, sharing the remaining 17%

  • One call gives a probability to each of the 256,000 tokens of the vocabulary.
  • The next token is drawn at random from these probabilities.
  • This random draw lets two runs on the same text write different documents.
